# LAST LIGHT and SEEDLIGHT

Two animated shorts directed by Minseok Kang using the drawing framework from [BLACKOUT by anstapnever](https://github.com/anstapnever/blackout).

- **LAST LIGHT** (Opus 5.5, 73 seconds). A fox girl relights a lighthouse during a storm. [Source](last-light/)
- **SEEDLIGHT** (Fable 5.2, 78 seconds). A one-armed lantern automaton awakens in a desert fortress. A study of movement and timing in *Castle in the Sky*, with new characters and settings. [Source](seedlight/)

Each folder contains the film's three.js scene code, camera and animation timing, rendering tools, and audio source. See the individual vendor notices and audio credits in each folder. Downloadable audio sample libraries and rendered movies are omitted.

The original BLACKOUT MIT license is included in each project.
